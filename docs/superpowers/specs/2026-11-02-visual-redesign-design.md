# 《此生》整站视觉重设计

状态：早期人生画册草案已由用户最终确认的「织物刺绣」参考图替代。最终实施以 2026-11-02-textile-rebuild.md 为准。原始玩法和验证边界继续沿用。

## 目标

用户反馈是整个网页不好看，并希望重新获得清晰的实际网页截图。范围覆盖首页、出生资料、人生过程和总结卡，同时统一其余页面的基础视觉。不是只修改中国场景。

保留已有游戏功能、随机出生、首页概率圆环图、国家姓名与父母背景、人生选择、存档和总结卡。以现有项目继续开发。

## 当前发现

- 实际窄屏截图中的三张介绍卡仍横向挤在一起，标题和正文断行过碎。
- 页面同时加载 globals.css、readability.css、layout-balance.css 和 illustrated-journal.css；多轮覆盖使布局规则难以保持一致。
- 资料页存在外层卡片、介绍卡、资料框和父母卡等多层边界，视觉较繁复。
- 游戏身份区与主事件争夺首屏空间；需要明确正在发生什么、玩家下一步做什么。

## 视觉方向

推荐「人生画册」：沿用温暖、安静的品牌感觉，以纸白底色、深墨绿文字和少量暖金强调，大幅插画配合清楚的标题层级。适合现有手绘素材和用户喜欢的文案。

备选「沉浸游戏」：深色场景与事件主导，游戏感更强，但会明显改变当前温暖风格。

备选「清爽现代」：浅色简洁布局、操作优先，阅读效率高，但故事感较弱。

用户已确认推荐的「人生画册」方向。

## 页面调整

1. 首页：保留“如果重来，你会是谁？”和圆环图。桌面端采用均衡双栏，标题与开始按钮形成第一视觉重点；概率说明和详细统计展开查看。移动端按标题、开始、圆环的顺序排布，介绍区改为大图纵向内容。
2. 出生：大场景图与姓名形成一张完整的档案开页。出生地、年份和家庭信息用整齐的网格与分隔线呈现，减少嵌套边框；父母资料并列，手机端自然转为上下排列。
3. 人生过程：把角色资料压缩成紧凑页眉，放大事件标题、场景和选择按钮。状态与账本分出主次，年纪、年份和播放控制位置稳定。
4. 总结卡：采用一本人生画册的扉页结构，姓名、起止年份、代表场景、重要时刻形成清楚的阅读顺序；兼顾手机查看和图片导出。
5. 其余页面：统一导航、按钮、输入框、间距和标题样式，完整保留已有操作入口。

## 排版与响应式

桌面最大内容宽度约 1200–1280px，页面左右边距一致；手机使用单栏，不为追求对称把文字挤进狭长小格。正文使用清楚的无衬线字体，重要标题使用宋体风格，常规正文保持约 16px 及舒适行距。左右视觉平衡以内容和留白实现。

## 实施与验收

整理现有样式归属，避免再叠加一份临时覆盖文件。检查 390px、768px、1440px 等宽度，确保图标与文字不重叠，长姓名不溢出，选择和存档流程可用。验证构建后更新现有公开网站。
