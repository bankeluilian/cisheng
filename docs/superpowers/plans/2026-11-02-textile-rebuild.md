# 此生织物刺绣整站重建

用户已确认首页及出生、游戏、总结三张刺绣效果图，并要求增加图片图标、基于原始功能重新做并替换旧界面。

## 实施边界

- 使用现有项目与公开地址，替换旧界面和未发布的画册样式，不新建平行站点。
- 保留真实人生引擎、出生权重、改名、年度行动、关系、财务、档案、导入导出和分享流程。
- 不删除玩家存档、云端故事、Git历史或项目功能书。删除废弃展示样式可通过Git回退。
- 完整功能书尚未开发的项目不因本轮视觉重建而冒充已实现。

## 任务

- [x] 制作首页主视觉、六张刺绣生活场景、十二个刺绣图标和布纹素材。
- [x] 首页改用独立组件，按参考图组织大图、标题、双按钮、下方概率图和更多生活图片。
- [x] 替换旧排版入口，统一布纹、缝线、图标、资料页、事件、档案和总结卡；兼顾手机、深色、大字、打印。
- [x] 将新增图形接到真实数据及操作，保留各地区旧图目录，增强PNG导出与离线记录册的主题一致性。
- [x] 运行类型、单元测试、两端构建；真实浏览器验证出生、选择、改名、导出、手机菜单及存档。
- [ ] 独立审查后发布到原Sites地址和GitHub Pages；验证线上新界面并保存实际截图。

## 验收重点

390px手机无横向溢出；动态姓名及数据不用图片伪装；图表交互与概率有效；不能因换图导致随机状态变化；更多图片按需加载；展开侧栏不落在全部日记之后；深色和大字文字可读。

## 本轮验证记录

- TypeScript 无错误；51项单元测试通过；Pages 与 Vinext 构建通过。
- 浏览器验证空白出生、随机出生、改名、选择事件、刷新后档案保存，以及 PNG 和离线记录册实际下载。
- 手机尺寸含大字模式无横向溢出，展开生活侧栏位于全部小记之前。
- 独立审查的深色抽样按钮和深色打印文字问题已修复，浏览器计算颜色验证通过；Canvas圆角增加旧浏览器矩形回退。
- 图片不会消耗随机状态；国家/年代场景继续保留，六张通用生活场景新增刺绣版本，避免各国全部变为同一地点。
