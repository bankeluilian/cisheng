# 信封与车票元素

按用户要求，在既有刺绣游戏中加入可拆开的回信信封、迁居剧情的纪念车票，以及对应的小物标记。使用真实事件和纪念物数据，不随机生成新事实；出生、人生引擎与存档结构保持兼容。车票只在迁居抉择或实际已留下车票的那一年出现，明确区分待决定/已启程，不生成虚构真实车次、票价或具体城市。信封在回信剧情中可用鼠标和键盘展开，读信与选择仍走原流程。

验证：小物类型与纪念票来源单元测试；信封展开/收起、选择后结果、手机、深色以及卡片PNG；类型检查、现有测试及双端构建。更新原GitHub Pages与Sites地址。

## 核验结果
56项单元测试、TypeScript、Pages及Vinext构建通过。浏览器实测拆信/收信与空格键操作；迁居选择前显示待决定，选择出发后显示已启程和真实事件年份；窄屏无横向溢出，深色文字可读；带信封标记的PNG卡片下载成功。截图为测试存档实页，保存至宣传素材/信封车票-20261104。
