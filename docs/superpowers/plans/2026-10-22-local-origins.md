# Local names and parents birth occupations

Goal: names fit the birthplace, and parents have persisted birth-time work profiles based on local sector structure and existing family circumstances.

Scope: existing life creation and relationships; no new country selection, no nationality or ethnicity inference, no rewrite of old names or finances.

1. Add a deterministic name catalog with country mappings and marked regional fallbacks. Use native Japanese/Korean/Chinese names and readable names for other profiles. Sample representative traditions, not population frequency claims. Keep manual renaming and local generation separate from the fate RNG.
2. Download official World Bank/ILO 2023 agricultural, industrial and services employment shares. Preserve missing data and provide explicit country → regional → world → game fallback. Sector weights guide fictional work examples; job titles and employment arrangements remain game rules and are not population statistics.
3. Generate parents birth-time occupations using an independent seed channel. Existing resource tier weights the job examples and work arrangement; gender does not restrict available jobs. Persist optional validated fields and enrich legacy saves without altering identity, history, money or RNG.
4. Show parents work in birth and relationships, retain it in exports, provide local-name generation in the rename dialog, update rules and data notes. Test all 217 economies, Japanese identity, deterministic old-save migration, sector frequencies and malformed imports.
5. Verify phone and desktop, complete code review, build and deploy to the existing private Site.
